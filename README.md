# TR-commerce
# 🛒 Full-Stack E-commerce Website (MERN)

This is a full-stack e-commerce website built using the **MERN stack (MongoDB, Express.js, React, Node.js)**. The goal of this project is to improve our skills in both front-end and back-end web development.

---

## 🚀 Features

### 👨‍💻 Frontend (React)
- Responsive layout & modern UI
- Navigation bar with active state
- Product sliders
- Wishlist, cart & user login
- Search bar with navigation
- Dynamic pages (Men, Women, Kids, Discover)

### 🔧 Backend (Express.js + MongoDB)
- RESTful API for products, users, cart, etc.
- MongoDB for persistent data storage
- User authentication (coming soon)
- Secure and scalable Express server

---

| Stack Layer | Tech |
